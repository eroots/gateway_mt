# Synthetic test dataset

A small, fully synthetic MT dataset used by the tests and the "testing
your installation" docs. Generated by `tests/data/make_synthetic.py`;
re-running that script reproduces these files exactly (on Windows the
inversion-format files come out with CRLF line endings, which Git
normalises back to LF).

## Survey

* 30 sites (`SYN001`-`SYN030`) on a jittered 6 x 5 grid, ~5 km apart,
  centred at 49.0 N, 84.5 W (UTM zone 16U).
* 40 periods from 0.001 s to 5000 s, except `SYN029` and `SYN030`, which
  stop at ~470 s (AMT-style). `SYN030` has no tipper.

## How the responses are built

* Analytic 1-D layered-earth impedances: a resistive upper crust, a
  conductive layer whose depth and resistivity vary across the grid,
  resistive lower crust and a 100 ohm-m mantle.
* The conductor is ~8x more resistive in the yx polarisation than in xy,
  so the two curves split as they would over 2-D structure.
* The impedance tensor is rotated to a strike that changes across the
  grid (non-zero diagonals). `SYN005`, `SYN012` and `SYN023` carry
  galvanic distortion (static shift).
* Tipper: an anomaly centred ~2 km N / 3 km W of the grid centre, peaking
  around 10 s.
* Errors: 3% of sqrt(|Zxy Zyx|) on every impedance element, 0.02 on the
  tipper. Gaussian noise of that size is added to the EDIs.

## Files

| File | Contents |
|---|---|
| `edis/*.edi`, `edis/synthetic.lst` | Raw data (SEG EDI; variances in the `.VAR` blocks) and the site list |
| `synthetic_modem.dat` | ModEM data file: 18 of the 40 periods, full impedance + tipper. Periods outside a site's recorded band are flagged |
| `synthetic_modem_resp.dat` | Noise-free values at the same points, as a ModEM response (RMS ~1 against the data) |
| `synthetic_ws.data` | Same data, WSINV3DMT format |
| `synthetic_gofem.gdat`, `frequencies`, `receivers_projected.csv` | Same data, GoFEM format, with its frequency and receiver files |
| `synthetic_mare2dem.emdata` | Same data, MARE2DEM format (as written by gateway_mt) |
| `synthetic.model` | ModEM model (32 x 32 x 35 cells): the layered background plus the conductor |
| `synthetic.pymt` | Project / start-up file tying the list, data, response and model together (paths relative to this folder) |

The inversion-format files are written by gateway_mt itself from the EDIs, so
they also reflect gateway_mt's writers.
